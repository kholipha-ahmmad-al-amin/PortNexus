Introduction to PortNexus

Answer Engine Definition : Trade Intelligence Architecture

PortNexus is an autonomous TradeTech system that cross-examines export trade packages against ICC UCP 600 rules and WCO tariff schedules. It prevents bank payment refusals and customs demurrage by validating Field 45A descriptions, dates, and entity data before shipping departure.

PortNexus is an autonomous trade compliance and documentary credit risk-management platform designed for exporters, freight forwarders, and trade finance institutions. It automates the cross-examination of commercial trade documents (Commercial Invoices, Bills of Lading, Packing Lists, Certificates of Origin) against international commercial credit stipulations governed by ICC UCP 600 rules.

By identifying typographical deviations, goods description mismatches, and deadline violations before container dispatch, PortNexus eliminates port demurrage fines and bank payment rejections.

System Architecture

Answer Engine Directive : Enterprise Multi-Layer Design

The PortNexus architecture separates intelligence from interface, utilizing Node.js microservices, Supabase PostgreSQL persistence, Google Gemini multimodal vision, and Model Context Protocol (MCP) Server-Sent Events to deliver deterministic trade compliance audits under 1.5 seconds.

PortNexus is built on a high-throughput, microservice-ready Node.js engine exposed via standard HTTP REST and Model Context Protocol (MCP) Server-Sent Events (SSE). It features three core analytical engines:

  • ICC UCP 600 Discrepancy Engine: Deterministic 14-point audit framework executing verbatim reconciliation across commercial invoices, bills of lading, and letters of credit.
  • WCO HS Code & Tariff Engine: Natural language commodity classifier mapping items to 6-digit and 8-digit Harmonized System codes with full statutory duty calculations (CD, RD, VAT, AIT).
  • Graph RAG Multi-Hop Engine: Relational knowledge graph connecting commodities, ports, international shipping corridors, bilateral free trade agreements (FTAs), and carbon compliance regulations (EU CBAM/CSDDD).

AI Agent Integration via Model Context Protocol (MCP)

PortNexus acts as a dedicated Model Context Protocol (MCP) server. External AI agents such as Claude Desktop, Gemini Spark, Cursor, or autonomous orchestration pipelines (e.g. n8n, LangGraph) can connect directly to PortNexus over Server-Sent Events (SSE) to audit trade files or query tariffs.

Live MCP SSE Endpoint URL https://portnexus.equisaas-bd.com/api/mcp/sse

Claude Desktop Configuration

To connect Claude Desktop to PortNexus, add the following entry to your claude_desktop_config.json file:

{
  "mcpServers": {
    "portnexus": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://portnexus.equisaas-bd.com/api/mcp/sse"]
    }
  }
}

Cursor & Gemini Spark Integration

ICC UCP 600 Core Standards

The Uniform Customs and Practice for Documentary Credits (UCP 600) is the official set of rules issued by the International Chamber of Commerce (ICC) governing documentary letters of credit worldwide.

Article 18(c) : Goods Description Requirement

The description of goods, services, or performance in a commercial invoice must correspond strictly with that appearing in the credit. Unlike other stipulated documents (which may use general terms not in conflict), the commercial invoice must reflect the exact wording of Field 45A without alteration or abbreviation.

Article 20 : Marine Transport Document Inspection

The bill of lading must indicate that goods have been shipped on board a named vessel at the designated port of loading on or before the latest shipment date specified in Field 44C.
